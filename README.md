# Python-Pandas
# Retail & Sales Data Analysis Project

## Overview
This project was completed as part of a **Data Technician Bootcamp** and demonstrates the practical application of Python for data exploration, cleaning, transformation, and analysis of retail and sales datasets. The project focuses on using the **pandas** library to prepare data, uncover trends, and generate insights that support data-driven decision-making.

## Skills Demonstrated

### Data Exploration & Analysis
- Examined retail and sales datasets to identify patterns, trends, and potential data quality issues.
- Performed filtering and data selection using:
  - Boolean indexing
  - `.loc[]` for label-based selection
  - `.iloc[]` for position-based selection
- Analysed customer, product, and sales performance metrics.

### Data Cleaning & Preparation
- Handled missing and incomplete data using:
  - `dropna()`
  - `fillna()`
- Removed duplicates and corrected inconsistencies.
- Renamed, reformatted, and transformed columns to improve data usability.
- Prepared datasets for further analysis and reporting.

### Data Manipulation with Pandas
Used a range of pandas functions and techniques, including:
- `groupby()` for aggregating and summarising sales data
- `sort_values()` for ranking products, customers, and regions
- `merge()` and `concat()` for combining datasets
- `value_counts()` for frequency analysis
- `describe()` for statistical summaries
- Filtering, slicing, and conditional logic to extract meaningful insights

### Data Visualisation
- Created charts and visual summaries to communicate findings effectively.
- Utilised:
  - Pandas built-in plotting functionality
  - `matplotlib` for customised visualisations
- Generated visual insights such as:
  - Sales trends over time
  - Product performance comparisons
  - Regional sales distributions
  - Customer purchasing patterns

## Key Outcomes
- Improved understanding of real-world retail and sales data structures.
- Developed practical skills in data cleaning, preparation, and exploratory data analysis (EDA).
- Applied analytical techniques to identify trends, outliers, and business opportunities.
- Produced clear visualisations that supported interpretation and presentation of findings.
